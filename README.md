# دیتابیس بازی اسم و فامیل

- فقط حروف فارسی استاندارد
- بدون اعراب (حرکات)
- بدون حروف عربی خاص (مثل ة ئ ؤ أ إ)
- بدون علائم نگارشی، اعداد، حروف انگلیسی و ریاضی
- بدون فاصله در اکثر دسته‌ها (کلمات تکی)
- در نام‌ها، فامیلی، شهر و کشور فاصله مجاز برای ترکیبات خالص فارسی
