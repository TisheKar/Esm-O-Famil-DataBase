## ✅ استانداردها

- كلمات با خط فارسي استاندارد (ك، ي)
- بدون اعراب و علائم نگارشي
- حداقل ۲ حرف
- مرتب‌سازي الفباي فارسي (آابپتثجچحخدذرزژسشصضطظعغفقکگلمنوهی)
- فاميلي‌ها: تكلمه (فاصله‌دارها حذف شده)
- اسامي: تنها مركبات سنتي (علي اصغر، علي اكبر)
- شهرها: همه شهرها، شهرک‌ها، محلات (بدون پيشوند شهرک/شماره)
- حيووانات: پستانداران، پرندگان، خزندگان، آبزيان، حشره‌ها
- رنگ‌ها: رنگ‌های اصلي، ثانويه، متالیک، نئونی، سنتي ايراني
- ميوه‌ها: ميوه‌های خوش‌خومه، خشک، استوایی، مغازی، باری
- گل‌ها: گل‌های بومی، باغی، اکزوتیک، فصلی، دارویی
- غذاها: دمپخت، آش، خوراک، پلو، کباب، شوربا، شیرینی، نان، مشروبات، منطقه‌ای
- مشاغل: پزشکی، مهندسی، آموزشی، اداری، هنری، خدمات، کشاورزی، ساختمانی
- اعتبارسنجي با ویکی‌پديا و ديتاست‌های رسمي (armanyazdi, farbodbj, mhndev/iran-geography)
