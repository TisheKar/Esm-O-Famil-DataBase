## 📁 ساختار فایل‌ها

هر فایل شامل لیستی از کلمات فارسی هست:
- هر خط یک کلمه
- بدون تکرار
- مرتب شده (الفبای فارسی: آابپتثجچحخذرزژسشصضطظعغفقکگلمنوهی)
- فیلتر normalize: تبدیل عربی→فارسی، حذف اعراب، حداقل ۲ حرف

## 🎯 نحوه استفاده

### پایتون:
```python
def load_words(category):
    with open(f'{category}.txt', 'r', encoding='utf-8') as f:
        return [line.strip() for line in f if line.strip()]

animals = load_words('animals')
print(f'تعداد حیوانات: {len(animals)}')
```

### جاوا اسکریپت:
```javascript
const fs = require('fs');

function loadWords(category) {
    const content = fs.readFileSync(`${category}.txt`, 'utf-8');
    return content.split('\n').filter(line => line.trim());
}

const animals = loadWords('animals');
console.log(`تعداد حیوانات: ${animals.length}`);
```

## 📝 قوانین بازی

1. حرف اول کلمه مشخص میشه
2. بازیکن‌ها باید برای هر دسته کلمه پیدا کنن
3. اگه کسی کلمه تکراری بگه یا اشتباه بنویسه، امتیاز منفی میگیره
4. سریع‌ترین بازیکن برنده میشه

## 🔧 قوانین دیتابیس

- فقط **۱۲ دسته مجاز**: حیوانات، ماشین، شهرها، رنگ‌ها، کشورها، گل‌ها، غذاها، میوه‌ها، مشاغل، اشیاء، اسامی، فامیلی
- کلمات باید **فارسی** باشند (انگلیسی حذف میشه)
- حروف عربی → فارسی نرمالایز میشن (ك→ک، ي→ی، ة→ه)
- اعراب حذف میشن
- حداقل ۲ حرف
- بدون تکرار درون هر فایل
- مرتب شده الفبایی فارسی
- تکراری **بین** فایل‌ها مجازه (مثلاً «گل» هم در گل‌ها و هم در اشیاء)
